# JavaScript Task Dashboard

A small browser-based task dashboard built with plain JavaScript.

## What it demonstrates

- DOM manipulation
- JavaScript arrays and objects
- Event handling
- Form validation
- Filtering and state management
- LocalStorage persistence
- Clean UI logic
- Basic QA-oriented behavior

## Features

- Add tasks
- Choose task priority
- Mark tasks as completed
- Filter by all / open / completed
- Remove tasks
- Prevent empty task names
- Persist tasks in the browser with LocalStorage

## Run

Open `index.html` in any modern browser.

No external dependencies are required.

## Project purpose

This repository demonstrates practical JavaScript problem solving through a simple task-management interface. It focuses on clear logic, user interaction, validation and maintainable code.
